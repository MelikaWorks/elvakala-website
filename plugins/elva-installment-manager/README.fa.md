# رفع محدودیت‌های فروش اقساطی مبتنی بر افزونه DenaPay برای ELVA

این مخزن، مطالعه موردی مهندسی، مسیر تحقیق و ابزارهای آزمایشی امن برای رفع
محدودیت‌ها و توسعه قابلیت‌های فروش اقساطی مبتنی بر افزونه DenaPay در ووکامرس
است.

> این مخزن سورس افزونه تجاری نیست. Rule Manager نهایی، موتور Sync گروهی، اتصال
> Bazara/محک و Auto Price Sync عمداً خصوصی نگه داشته شده‌اند.

## مسئله

DenaPay امکان تعریف پلن عمومی و پلن اختصاصی برای هر محصول را داشت، اما الوا
نیاز داشت برای گروه‌های مختلف محصولات قوانین درصدی متفاوت تعیین کند؛ بدون
اینکه صدها محصول دستی ویرایش شوند.

مثال:

```text
گروه محصول A → ۳۰٪ پیش‌پرداخت + ۵ چک
گروه محصول B → ۲۰٪ پیش‌پرداخت + ۴ چک
```

برای حل مسئله دو مسیر بررسی شد.

## مسیر اول — MehranPay و فیلتر پلن‌های عمومی

در مسیر اول تنظیمات DenaPay توسعه داده شد تا هر Plan بتواند عمومی یا مخصوص
دسته‌های انتخاب‌شده باشد. رابط تنظیمات و انتخاب دسته‌ها کار کرد، اما DenaPay
پلن‌های عمومی را از چند مسیر داخلی جداگانه می‌خواند. در نتیجه احتمال داشت
صفحه محصول، سبد و Checkout نتایج متفاوتی داشته باشند. در تست نیز محصول نمونه
هر سه Plan را نمایش داد.

این مسیر Rollback شد و فقط به‌عنوان Prototype آرشیوشده در مخزن باقی می‌ماند.

## مسیر دوم — تولید متادیتای اختصاصی محصول

در مسیر موفق، به‌جای فیلترکردن چند مسیر داخلی DenaPay، از ساختار متادیتای
اختصاصی خود محصول استفاده شد:

```text
قانون کسب‌وکار
  ← انتخاب محصولات منطبق
  ← خواندن قیمت روز
  ← محاسبه مبالغ
  ← تولید متادیتای سازگار با DenaPay
  ← نمایش و پردازش طبیعی توسط DenaPay
```

مراحل تأییدشده:

- استخراج متادیتای محصولی که دستی تنظیم شده بود
- تست فرمول درصدی
- نوشتن کنترل‌شده روی یک محصول
- مشاهده پلن تولیدشده در فرانت‌اند DenaPay
- Dry Run دسته‌ای روی ۱۳ محصول
- ساخت و تست خصوصی افزودن، ویرایش و حذف قوانین
- اجرای Sync کنترل‌شده روی ۱۳ محصول
- بررسی تشخیص خودکار تغییر قیمت

بعد از آخرین Sync با قانون ۳۰٪، چهار چک و چهار ماه، صفحه محصول دوباره بررسی
نشد. بنابراین فقط گزارش `SYNCED ✓` را ثبت می‌کنیم و ادعای مشاهده نتیجه نهایی
در فرانت‌اند نداریم.

## کدهای قابل انتشار

- Prototype آرشیوشده MehranPay
- ابزار فقط‌خواندنی Product Meta Inspector
- تست محاسبه تک‌محصولی بدون ذخیره
- Category Dry Run بدون ذخیره

## کدهای خصوصی و منتشرنشده

- منوی نهایی افزونه و Rules Manager
- ذخیره، ویرایش و حذف قوانین Production
- Saved Rules Runner
- Sync واقعی و گروهی محصولات
- Metadata Writer نهایی
- Auto Price Sync
- Listener و Flagهای Bazara/محک
- ZIP نصب‌شدنی محصول تجاری

## وضعیت نهایی ثبت‌شده

معماری متادیتای محصول و اجرای کنترل‌شده گروهی موفق بودند. اتصال خودکار پس از
تغییر قیمت از مسیر واقعی Bazara/محک هنوز نیازمند بررسی و تکمیل بود.
