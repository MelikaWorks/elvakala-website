# ELVA KALA Shared Screenshots

This directory is reserved for repository-level screenshots that support more than one project or do not have a clear component-specific location.

## Preferred Placement

Whenever possible, keep screenshots beside the code or documentation they explain:

- Elementor screenshots under the relevant `elementor/` component
- Performance evidence under the relevant `performance/` investigation
- Plugin screenshots inside the related plugin project
- SEO screenshots under the relevant `seo/` check

Use this shared directory only for cross-project images, repository overviews, or temporary evidence awaiting classification.

## Naming Convention

Use descriptive English filenames:

```text
01-feature-before.png
02-feature-after.png
03-validation-result.png
```

Avoid generic filenames such as `1.png`, `new.png`, or random identifiers.

## Privacy Checklist

Before committing a screenshot, verify that it does not expose:

- Passwords or access tokens
- Customer names, phone numbers, addresses, or order details
- Private email addresses
- Server paths or sensitive configuration
- Browser sessions or authentication information
- Commercial source code that must remain private

Crop or redact sensitive areas before publication.
