# گزارش بررسی ریپازیتوری — ۲۰۲۶-۱۱-۱۵

[English](REPOSITORY_REVIEW.md)

## دامنه بررسی

فهرست بازگشتی مخزن و تمام ۱۱۰ فایل متنی PHP، Markdown، HTML، CSS، JavaScript و htaccess دریافت شدند. لینک‌های داخلی و مسیر تصاویر مستندات با فایل‌های واقعی تطبیق داده شدند و کدهای اختصاصی به‌صورت هدفمند بررسی ایستا شدند. این بررسی تأیید امنیت خط‌به‌خط یا تست دوباره سایت نیست.

- بررسی نحوی ۳ فایل مستقل JavaScript و ۵ بلوک ثابت داخل فایل‌ها موفق بود؛ ۲ بلوک تولیدشده با PHP بررسی نحوی نشدند.
- دو مسیر تصویر Extendify اصلاح شد.
- نام فایل‌های ارجاع‌شده برای بارگذاری CSS فشرده، استایل فوتر، کد Extendify و دو تصویر اقساط اصلاح شد.
- معرفی NikSMS و Extendify به فهرست‌های بالادستی اضافه شد.
- جست‌وجوی هدفمند در PHP و HTML برای اطلاعات حساس، در کدهای روبیکا فقط توکن جای‌خالی نشان داد؛ این بررسی جامع اسرار نیست.
- تصاویر فقط فهرست شدند؛ محتوای تصویری، لینک‌های خارجی و تاریخچه گیت بررسی نشدند.
- PHP CLI و محیط وردپرس در دسترس نبود؛ تست PHP، درگاه و خرید واقعی انجام نشد.

## موارد باقی‌مانده

| مورد | نتیجه و اقدام لازم |
| --- | --- |
| فایل‌های CSS فشرده | کد بارگذاری نام‌های دارای ` (1)` دارد ولی فایل‌های گیت بدون آن هستند؛ نام واقعی فایل‌های سرور و پاسخ شبکه باید بررسی شود. خطای فعلی 404 اثبات نشده است. |
| روبیکا | پرداخت واقعی هنوز تست نشده؛ قفل ارسال هم‌زمان و صف تلاش مجدد وجود ندارد. |
| دسترسی‌پذیری سبد خرید | مدیریت کامل فوکوس، بازگرداندن فوکوس و جلوگیری از دسترسی کیبورد به محتوای بسته در کد دیده نمی‌شود؛ نیازمند تست رابط و اصلاح است. |
| سرعت فیلتر محصول | کد همه شناسه‌های محصولات منطبق را می‌گیرد؛ برای کاتالوگ بزرگ نیازمند اندازه‌گیری زمان و تعداد کوئری است. |
| آزمایش‌های قدیمی اقساط | bootstrap به کلاس‌های منتشرنشده وابسته است؛ محاسبات آزمایشی از قیمت جاری و گردکردن استفاده می‌کنند و جایگزین موتور نهایی نیستند. |
| نصب کدها | فایل‌های تاریخی عمدتاً قطعه‌کد WPCode هستند؛ کل مخزن افزونه قابل‌نصب نیست. |
| انتشار عمومی | نسخه‌هایی از CSS/JS قالب و کتابخانه شخص ثالث داخل مخزن هستند؛ مجوز بازنشر و ذکر منبع باید بررسی شود. در این مرور درباره مجوز حکم قطعی داده نشده است. |

جزئیات، مسیر فایل‌ها و پیشنهاد بررسی هر مورد در [گزارش انگلیسی](REPOSITORY_REVIEW.md) آمده است. سایت و منطق کدهای اجرایی تغییر نکرده‌اند.
